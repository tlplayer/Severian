## Appendix

All model/API names below are proposed contracts for the rebuilt MLIR subsystem.

| Term / name | Kind | Meaning |
|---|---|---|
| MLIR | Target IR framework | Structured operations, regions, blocks, values, types and attributes with dialect-specific contracts. |
| Dialect | Operation/type family | Supplies target operation definitions and verification/conversion behavior. |
| Generic operation | Representation term | Structurally described target operation; distinct from a generic source callable or type parameter. |
| Atomic semantic operation | MIR term | Basic resolved execution step; can expand into multiple MLIR operations. |
| Memory atomic | Effect | Synchronized memory operation whose ordering and scope must survive conversion. |
| `MlirProgram` | Class | Owns target symbols, operations, regions and source locations. |
| `MlirOperation` | Class | Operation identity, operands/results, attributes, nested regions and successors. |
| `MlirRegion`, `MlirBlock`, `MlirValue` | Classes | Nested execution region, ordered operation block and typed value identity. |
| `MlirType`, `MlirAttribute`, `MlirLocation` | Contracts | Target representation, typed metadata and original source/expansion origin. |
| `MlirBuilder` | Class | Checked construction and insertion into one target program. |
| `ConversionPlan` | Class | Input legality, destination legality, type/operation conversions and ordered pass requirements. |
| `ConversionResult` | Class | Converted program, updated identity/provenance maps and verification result. |
| `BackendRequest`, `Artifact` | Classes | Target/options/output request and produced artifact with exported/imported contracts. |
| `create`, `verify`, `convert`, `render`, `emit` | Functions | Construct, check, convert, print and compile structured IR. |
| `builder`, `operation`, `program`, `plan`, `request` | API parameters | Construction context, typed operation, target IR, conversion specification and backend request. |
| `Diagnostic` | Failure contract | Compiler stage, backend details and mapped source location. |
| `.mlir`, `.o`, `.a`, `.so` | Formats | Diagnostic/interchange text and native artifacts; artifact packaging/linking belongs to package flow. |

## Lowered operations → typed objects → checks

`text` blocks specify proposed builder records and assertions, not an external MLIR API or an implemented test harness. Humans run tests.

### Build and print typed addition

```sev
def add(x: i32, y: i32) -> i32:
    return x + y

test "source result survives target construction":
    assert(add(2, 3) == 5)
```

```text
Input: LIR-selected implementation of add, including overflow behavior.
Fixture below: target addition contract matches the selected provider;
any required overflow checks are additional typed operations.

MlirProgram P0
  function symbol: add
  region R0
    block B0(%x: target.i32, %y: target.i32)
      O0:
        identity: selected target addition
        operands: [%x, %y]
        results: [%sum: target.i32]
        attributes: provider-required typed attributes
        regions: []
        successors: []
        location: source span of "x + y"
      O1:
        identity: selected target return
        operands: [%sum]
        results: []
        location: source return span

assert P0 owns R0, R0 owns B0, B0 owns O0 and O1
assert O0 owns %sum; O1 references that same value
assert operand/result contracts pass dialect verification
assert literal 2 uses the concrete i32 value/type provider
assert builder never recovers types by parsing printed source text

before = (P0.revision, operation count, coverage call count, cleanup count)
first = render(verify(P0))
second = render(verify(P0))
assert first == second
assert before == (P0.revision, operation count, coverage call count, cleanup count)
```

### Aggregate conversion updates every use

```text
Input semantic contract:
  Pair(x: i32, y: i32)
  make() -> Pair
  consumer block B1(pair: Pair)

Fixture destination: Pair → [target.i32, target.i32]

Required conversion:
  make signature: () -> (i32, i32)
  make return: return %x, %y
  caller: (%x, %y) = call make()
  edge: branch B1(%x, %y)
  B1 arguments: (%x: i32, %y: i32)

assert declaration, call, return and edge types agree
assert value maps and type-bearing attributes are updated together
assert generated adapters retain source expansion paths
assert changing only make's declaration fails verification
```

### Accepted input must become legal backend output

```text
Input operation: selected collection indexing
Plan:
  accepted input: collection indexing with bounds/failure contract
  conversion: bounds check → conditional paths → address computation → load
  legal destination: selected backend's supported operation/type set
  requirements: declared failure/runtime symbols

assert verification runs before conversion and after relevant stages
assert final program contains no illegal collection operation
assert bounds, failure, destruction and effect order are preserved
assert absent conversion reports original indexing span
assert unsupported operation produces no published native artifact
assert emission receives resolved imports; it never searches rendered text
```

### Builder, region, and emission rejection cases

```text
test "typed object ownership":
  use operand from P1 while building P0 → reject cross-program handle
  target a block outside the permitted region → reject successor scope
  use nested-region value outside its allowed scope → reject
  use value before its definition without dialect permission → reject
  supply i32 where selected operation requires bool → reject type
  construct unknown/unverified generic operation → no verification bypass
  terminate block twice → reject

test "backend result":
  verified target program + resolved runtime requirements → artifact
  backend verifier rejects O0 → diagnostic(stage, source span, backend details)
  assert exported symbols and interface signatures agree with artifact ABI
  assert package linking resolves declared imports
  assert backend configuration and program revision match verification evidence

test "conversion preserves synchronized effects":
  input: atomic load with acquire ordering and system scope
  supported conversion → identical synchronization contract
  unsupported target capability → source diagnostic; no artifact
  assert conversion does not reorder destruction across a required effect
```

## Responsibilities

| Owner | Responsibility |
|---|---|
| LIR providers | Select legal target types/operations and declare required conversions/runtime support. |
| Typed model and builder | Preserve object identity, insertion order, types, regions, successors and provenance. |
| Structural verifier | Check references, ownership of IR objects, symbol/region consistency and value scope. |
| Dialect/backend verifier | Validate the selected dialect operation/type contracts for the configured backend. |
| Conversion driver | Apply declared type/operation conversions and reject remaining illegal operations. |
| Backend adapter | Transfer verified IR, invoke native compilation and return artifacts/diagnostics. |
| Package flow | Choose output paths, cache, archive and link returned artifacts. |

## Data Models

```text
MlirOperation
  registered operation identity
  operands: references to typed values
  results: owned typed values
  attributes: typed metadata
  regions: owned nested regions
  successors: block references with operand contracts
  location: source and semantic expansion origin

ConversionPlan
  target and ABI
  accepted input operation/type contracts
  legal destination operation/type contracts
  conversion providers and ordered passes
  required capabilities/runtime symbols

ConversionResult
  program: converted MlirProgram
  value/symbol/origin maps updated by conversion
  verification evidence for this program revision and backend configuration
```

## API

```text
create(builder: MlirBuilder, operation: typed operation description)
    -> operation handle | diagnostics
verify(program: MlirProgram) -> checked program revision | diagnostics
convert(program: checked MlirProgram, plan: ConversionPlan)
    -> ConversionResult | diagnostics
render(program: checked MlirProgram) -> text | diagnostics
emit(program: checked MlirProgram, request: BackendRequest)
    -> Artifact | diagnostics
```
