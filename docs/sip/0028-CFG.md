## Source block → execution blocks → checks

`text` blocks specify expected IR and verifier assertions, not implemented inspection APIs. Integration fixtures enter through source → lexer → parser → HIR; malformed-graph fixtures exercise the verifier directly. Humans run tests.

### Branch values reach a join

```sev
def choose(flag: bool, x: int, y: int) -> int:
    z := x
    if flag:
        z = y
    return z

test "both branch values reach the result":
    assert(choose(false, 2, 3) == 2)
    assert(choose(true, 2, 3) == 3)
```

```text
B0(flag: bool, x: int, y: int):
  Conditional(flag, B1(), B2())
B1:
  Jump(B3(y))
B2:
  Jump(B3(x))
B3(z: int):
  Finish(z)

assert body.entry == B0
assert B3.parameters == [z: int]
assert predecessors(B3) == [B1, B2]
assert each incoming argument has type int
assert z is available at Finish
assert every completed reachable block has exactly one terminator
assert condition is a runtime value
assert source block parentage and BlockAddress remain unchanged
```

### Short-circuit evaluation protects an effect

```sev
def announce() -> bool:
    print("called")
    return true

def guarded(flag: bool) -> bool:
    return flag and announce()

test "false skips the call":
    assert(guarded(false) == false)

test "true evaluates the call":
    assert(guarded(true) == true)
```

```text
B0(flag: bool): Conditional(flag, B1(), B2(false))
B1: V0 = call announce(); Jump(B2(V0))
B2(result: bool): Finish(result)

assert announce exists only in B1.operations
assert false path contains zero calls to announce and zero print effects
assert true path contains one call to announce
assert call stays an operation, not an edge into announce's body
assert selected Boolean provider supplies the evaluation order
```

### Loop carries a value on its backedge

```sev
def count_to(limit: int) -> int:
    x := 0
    while x < limit:
        x += 1
    return x

test "zero and repeated iterations":
    assert(count_to(0) == 0)
    assert(count_to(3) == 3)
```

```text
B0(limit: int): Jump(B1(0))
B1(x: int):
  V0: bool = less(x, limit)
  Conditional(V0, B2(), B3(x))
B2:
  V1: int = add(x, 1)
  Jump(B1(V1))
B3(result: int): Finish(result)

assert B1 accepts int from both entry and backedge
assert limit dominates B1 and B2
assert ownership iterates the backedge until its facts stabilize
```

### Malformed graph and source-origin tests

```text
test "invalid edges and operands":
  change Jump(B3(x)) to Jump(B3()) → reject missing argument
  supply bool to B3(z: int) → reject type mismatch
  target nonexistent B9 → reject target bounds
  target another realization's B0 → reject body ownership
  use B1-local value in B3 without every-path availability → reject dominance
  insert operation after Finish → reject terminated block
  defined reachable block without terminator → reject incomplete body
  replace missing return with Dead → reject without unreachable proof

test "exit contracts":
  Jump and Conditional → check targets and edge arguments
  Finish and FinishFields → check declared results
  Raise → check declared error and ownership cleanup path
  Dead → require unreachable path
  unsupported suspension → diagnostic; no ReadyMir
  add exit variant → require exhaustive successor/verifier handlers

test "two files both contain block zero":
  first origin = BlockAddress(unit=0, block=0)
  second origin = BlockAddress(unit=1, block=0)
  assert origins differ
  split and compact execution blocks
  assert source addresses, parentage and submodule membership are unchanged
  assert operations and their aligned origins remain ordered
  assert CFG rewrites invalidate/remap ownership facts
  assert Block.contents still references source grammar nodes
```

## Responsibilities

| Owner | Responsibility |
|---|---|
| Block/operation provider | Specify evaluation order, conditional execution and control effects. |
| Builder | Allocate execution blocks and values, bind parameters and insert operations/terminators. |
| Verifier | Check structural flow, value availability, result contracts and provenance. |
| Ownership | Interpret storage effects over the checked paths. |
| LIR | Convert those paths into a supported target representation. |

## Data Models

```text
CfgBody
  owner: realization identity
  entry: execution-block index
  blocks: canonical execution records using Block
  parameters, result contract
  revision

ExecutionContext
  owner: realization
  body: reference to CfgBody
  insertion: unterminated execution block
  origin: qualified source and provider identity
```

## API

```text
build(realization, context: ExecutionContext) -> CfgBody | diagnostics
verify(realization, body: CfgBody) -> checked body revision | diagnostics
successors(exit: CfgExit) -> list[CfgEdge]
```

## Structure

| Proposed file | Responsibility |
|---|---|
| `cfg.sev` | Public construction/verification coordination. |
| `builder.sev` | Typed construction context and block/edge insertion. |
| `verify.sev` | Structural and contract checks. |
| `availability.sev` | Value definitions, dominance and join availability. |
| `rewrite.sev` | Checked graph rewrites, edge remapping and invalidation. |
